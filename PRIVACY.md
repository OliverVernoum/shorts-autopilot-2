# Privacy policy: Shorts Autopilot

Shorts Autopilot is a personal tool run by Oliver Vernoum to upload videos to his own YouTube channels.

- It requests the `youtube.upload` and `youtube.readonly` scopes only, to upload videos and confirm which channel is authorised.
- It is not offered to other users and collects no data about anyone else.
- OAuth tokens are stored only in a private, owner-only file on the channel owner's own server and are never shared.
- Access can be revoked at any time at https://myaccount.google.com/permissions.
